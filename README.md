# Sistema InfoTech — cópia separada para demonstração

Este repositório contém o **site anterior da InfoTech.io**, incluindo páginas de serviços, pedidos, autenticação, área do cliente e área administrativa.

## Objetivo
Ser uma cópia independente e futura demonstração do **Sistema InfoTech**, sem misturar seu código e dados com o portfólio oficial.

- **Site principal e portfólio:** [InfoTech.io](https://infotech-io.com.br/) — repositório [lucasjanoca/InfoTech.io](https://github.com/lucasjanoca/InfoTech.io).
- **Código do sistema antigo:** esta pasta raiz (não mais arquivado em subpasta).
- O nome técnico do repositório é temporário e poderá ser alterado depois.

## Segurança e publicação
A configuração Supabase foi substituída por um endereço fictício. **Login, envios e leitura de pedidos reais não funcionam aqui** até haver um projeto Supabase exclusivo de demonstração e as respectivas políticas de acesso (RLS), testes de autorização e ambiente isolado.

**Não aponte este projeto para o Supabase de produção.** Para uma demonstração navegável, use dados fictícios e não habilite solicitações reais.

O arquivo `CNAME` do antigo site foi retirado para evitar conflito com o domínio oficial `infotech-io.com.br`. Este repositório não deve assumir o domínio da InfoTech oficial nem o domínio antigo da pesquisa.
